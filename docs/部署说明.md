# 部署说明

> 适用：智学数研学生端 M2 后端（D:\math-arena\services\api）+ 前端（D:\frontend）

## 1. 环境要求

- Windows 10/11，Python 3.12，Node.js ≥ 20，Docker Desktop
- 后端依赖安装：cd D:\math-arena\services\api && python -m venv .venv && .venv\Scripts\pip install -r requirements.txt

## 2. 依赖服务

| 服务 | 启动方式 | 端口 |
|------|----------|------|
| Postgres | docker start math-arena-postgres（首次：docker compose -f deploy/docker-compose.yml up -d postgres） | 54329 |
| Redis | 本机 redis-server（或 docker start math-arena-redis） | 6379 |
| Embedding BGE-M3 | D:\math-arena\.tmp\embed-server\start.bat | 8080 |
| MinIO | docker start math-arena-minio | 9000 |

检查：docker inspect math-arena-postgres --format '{{.State.Health.Status}}' 应为 healthy。

## 3. 后端启动

```
cd D:\math-arena\services\api
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

- 生产/后台运行（脱离终端）：用 WMI 方式启动，日志落 .run_backend.log。
- Alembic 迁移已到 head（m2_012~m2_016）；新环境执行 .venv\Scripts\python.exe -m alembic upgrade head。
  m2_016 为错题去重（合并重复行 + 唯一索引 uq_error_records_user_question）。

## 4. 前端启动

```
cd D:\frontend
npm run dev                       （默认连真实后端，/api 代理到 127.0.0.1:8000）
set VITE_USE_MOCK=1 && npm run dev（需要假数据演示时显式开启 mock）
```

生产构建：npm run build（产物 dist/，nginx.conf 提供反代示例）。
注：迭代19 起前端默认连真实后端（原 VITE_REAL_API=1 开关改为 mock 反向开关 VITE_USE_MOCK=1）。

## 5. 配置说明（.env 于仓库根目录）

| 变量 | 说明 |
|------|------|
| DATABASE_URL / REDIS_URL | 数据库与缓存连接串 |
| DEEPSEEK_API_KEY / DEEPSEEK_MODEL / DEEPSEEK_BASE_URL | MiMo 主力通道（OpenAI 兼容） |
| SPARK_API_PASSWORD / SPARK_MODEL | 星火主通道（当前未配置，自动降级 MiMo） |
| XINGCHEN_ENABLED / XINGCHEN_API_KEY / XINGCHEN_API_SECRET / XINGCHEN_FLOW_IDS | 星辰工作流（flow_ids 为 JSON：8 个流注册，其中 wf_socratic/wf_doc_understand/wf_intent_router 已验证可用；chat 云轨已停用） |
| EMBEDDING_BASE_URL / RERANKER_BASE_URL | BGE-M3 向量服务 |
| STORAGE_PROVIDER / STORAGE_ENDPOINT_URL / STORAGE_BUCKET / STORAGE_ACCESS_KEY / STORAGE_SECRET_KEY | 对象存储（本机 MinIO；上云只改 STORAGE_* 与 EMBEDDING_PROVIDER） |
| DEV_SMS_CODE | 开发环境验证码（当前 123456） |
| JWT_SECRET | 令牌签名密钥 |

管理后台运行时覆盖：system_configs["model.global"]（主/备通道）、["xingchen.global"]（星辰凭证）、["workflows"]（flow_id/timeout）、用户级 user_integration_configs。改完即时生效（PUT 后清缓存）。

## 7. 注意事项

1. 短信验证码限流 60s/手机号，联调脚本需错开或换号。
2. 后端为单进程直跑（无 --reload），改代码后需重启。
3. 前端 vite 绑定 IPv6 localhost（127.0.0.1 探测不到属正常，用 localhost 访问）。
4. 星辰 chat 云轨已停用（丢上下文）；平台侧修好 wf_socratic_chat 输入透传后，恢复 agent_router 中的可选通道分支即可（_socratic_chat_stream 已保留）。
5. TAL 重标期间 practice/start 的 TAL 题难度会逐步变化，属预期。
