## 1. 首页 `/teacher-v3/prep`（基线 = `宪法/屏幕截图 2026-09-08 201621.png`）

**页面必须全幅独占**：不得渲染 TeacherV3Layout 的全局顶栏/副标题/任务入口（当前双击顶栏 = 直接降级，必须移除）。首页自带轻量品牌行（可选），或直接留白。

1. **背景**：白底 + 顶部径向浅色光斑（`#EEF2FF`/`#ECFEFF` 系，透明度 ≤0.5，无硬边）。禁止纯灰死板底色。
2. **Hero（居中，整块 ≤ 220px 高）**：问候「下午好，李老师 👋」（14 灰）→ 主问句「今天想备什么课？」（**34px/700**，其中「备」字主蓝）→ 副标题「告诉我课题、上传资料、AI 帮你生成完整教案」（14 灰）。
3. **NL 主输入卡**：**全圆角胶囊（radius 999）**，高 64px；左内衬回形针图标（弱色）；placeholder = 「输入课题，例如：人教A版选修一 椭圆及其标准方程 第1课时」；右端 40px 主蓝圆形发送钮（纸飞机），无文本时 45% 透明。折行时高度自适应但圆角保持胶囊。**禁止出现"继续上次会话"类信息噪音遮挡 placeholder**（需要时以右侧小徽标呈现）。
4. **轻提示行**：「支持语音输入 · 拖拽文件上传 · 选择教材章节」——**三项都必须是真实可用能力**；未接线者隐藏，不得禁用态上屏。
5. **四个入口卡**（等宽 grid，4 列，高 118px，卡内 padding 20px）：图标为 **不同色底圆角方块（40px）：教材=紫 `#EEF2FF/#4F46E5`、资料=蓝 `#E0F2FE/#0284C7`、模板=靛 `#EDE9FE/#7C3AED`、继续=琥珀 `#FEF3C7/#D97706`**；标题 15/600；描述 13 灰（**单行**，超出省略，禁止三行折行）。卡片必须真实跳转/预填；不可用能力的入口**整卡隐藏**（不是变灰长文案）。
6. **最近备课**：区标题「最近备课」15/600 + 右侧「查看全部 ›」蓝链 + 检索框（胶囊、宽 220）；列表项 = 左侧 36px 彩色圆角方块图标（按课型/状态着色）+ 标题 15/600 + 元信息 13 灰（`高二(1)班 · 新授课 · 昨天`）+ 右侧状态徽标（草稿=琥珀浅底 / 已完成=绿浅底 / 备课中=蓝浅底）+ chevron。行高 64px，行间 8px。空态 = 卡内插画位 + 一句引导 + 主按钮，禁止裸文案。
7. **右下 AI 助教圆钮**（52px 主蓝）保留；点击聚焦 NL 输入。
8. 禁止：底部/侧边出现任何来源不明的灰块、折叠残留、重复品牌名。

## 3. 课堂设计页（黄金图 1 + 本文件扩展）

结构自上而下：
1. 标题行（居中列，最大宽 1300）：`这节课的教学流程`（20/700）+ `（共 45 分钟）`13 灰；右侧胶囊「已考虑: 班级基础中等」（有画像才显示）。
2. **对话区（本文件新增裁决）**：黄金图未画对话面板，但备课流程必须让教师看见 AI 的提问与选择卡。裁决：**对话以"会话条"形式内嵌在流程上方**——最大宽 1300、白卡、可折叠（默认展开最近 2 条，`查看全部对话`展开滚动区，滚动区 max-height 360）。
   - 消息气泡：user 右对齐浅蓝底（`#EFF4FF`，主蓝文字），assistant 左对齐白底描边；圆角 10；行内 KaTeX。
   - 卡片型消息（选择卡/蓝图卡/证据轨/诊断卡）**占满会话条宽度**，禁止塞进气泡。
   - 输入统一走底部 AI 条（会话条内不放输入框），保持"唯一交互入口"。
   - 生成中：在最后一条 AI 消息下方显示阶段文案（来自服务端 `ai.stage`）+ 计时；**禁止假进度条**。
3. 教学流程时间轴：左轨竖线 + 节点圆点 10px（激活主蓝实心）；折叠行 = 序号徽标 28（激活蓝底白字）+ 环节名 15/700 + 时长 13 灰 + 一句摘要 14 灰 + chevron；展开卡 = 1.5px 主蓝描边 + `#F5F8FF` 底，内部左栏三组（教师提问/学生活动/板书要点，组名 14/700 + ✎编辑 13 蓝链）+ 右栏两卡（教材依据：封面缩略 88×118 + 书名 + 章节 + 引文块；教学提示：灯泡 + 「基于学情」胶囊 + 蓝点列表）。比例 ≈ 2:1。
4. 底部悬浮 AI 条：居中胶囊 ≈640px，左内「正在修改: 03 椭圆的定义 ×」浅蓝胶囊（可清除）；placeholder「告诉 AI 你想怎么改这节课...」；麦克风；右端 40 蓝圆发送。
5. 左下悬浮胶囊「📎 教材与资料 N ›」（N=真实 evidence 数；0 时仍显示但打开抽屉给空态说明）。
6. **性能红线**：本页必须 500ms 内完成首屏稳定渲染（可截图）；禁止导致渲染进程卡死的响应式循环（实测当前版本截图工具 45s 超时 = 阻断级缺陷，必须定位修复）。

## 6. 抽屉 / 弹层（黄金图未画 → 本文件裁决）

1. **教材与资料抽屉**（右侧 480 宽，白底阴影）：头部「教材与资料 N」+ X；分组：`教材依据`（卡片：教材名 + 章节 + 页码区间 + 原文片段，KaTeX 渲染 + `查看教材`按钮）/ `课堂资料`；底部「上传资料」（未接线则隐藏）。原文抽屉内可滚动，最大高 70vh。
2. **教材原文查看**（全屏遮罩 + 居中 900 宽文档卡）：头部教材名 + 章节 + 页码 + 权利状态徽标；正文按 chunk 顺序渲染（KaTeX）；右上 X。空/失败态给中文软提示 + 重试。
3. **历史版本**（右侧 480 抽屉）：时间线列表（时间 + 来源徽标 `教师/AI提案/系统` + 环节数 + 总时长 + 摘要），点击展开 diff 摘要；`回到此版本`为高风险动作，需二次确认。
4. **导出**（居中对话框 520 宽）：格式卡（PPTX / 教案 PDF / 教案 Word），产出说明 + 预计文件名；`开始导出` → 进度（真实任务状态轮询）→ 完成给下载按钮 + 打开所在任务链接；失败给原因 + 重试。
5. 所有弹层：Esc 关闭、点击遮罩关闭（高风险确认框除外）、焦点陷阱。
