## 1. 铁律（违反 = FAIL，不允许打折扣）

1. **反空壳**：任何按钮 = Trigger + State + Result 三者齐备且真实持久化；数字/时间/计数必须来自后端。
2. **反幻觉**：教材引用必须来自 `textbook_v2` 检索（SourceLocator）；禁止编造页码；禁止 AI 生成冒充教材例题。
3. **反内部泄漏**：`（教师修订）`「（教师新增）」「（待确认）」等**编辑内部标记与占位符禁止出现在任何渲染文本**（PPT 页标题、教案章节、大纲、顶栏、列表）。
4. **无深色面 / 无渐变 / 无玻璃拟态**：所有面板底 ≥ `#F0F0F0` 亮度。
5. **数学必须正确**：椭圆 `c² = a² − b²`（`a` 为长半轴时 `c=√(a²−b²)`）；公式一律 KaTeX 渲染，禁裸 LaTeX 源码上屏。
6. **教师主权**：AI 修改不得覆盖教师手工块；教师编辑必须落库且刷新/重进可还原。
7. **不缝补**：禁止以「现在的实现」为基线做局部补丁式美化。凡与黄金图/本文件冲突的既有结构，**推倒重做**。
8. **诚实降级**：未实现的能力不得渲染入口；未绑定班级不报错阻断，改为可继续的软提示。

圆角：卡片 12px / 面板 14px / 胶囊 999px / 徽标 8px。阴影：仅浮层（≤ `0 8px 24px rgba(15,23,42,.08)`）。
字号：页标题 20/700 · 区标题 15/600 · 正文 14 · 元信息 13 · 说明 12。行高 1.6。

### 2.2 版式
- 内容列居中，最大宽 **1280px**，左右留白对称。
- 卡片间距 12/16px 网格；禁止元素重叠、禁止绝对定位堆叠。
- 一屏内同层级视觉元素不超过 3 种样式。
- 中文标签，禁止英文码暴露给教师（`classroom/ppt/plan` 等只允许出现在 URL）。

### 2.3 必须成套覆盖的状态（缺一即 FAIL）
每个真实界面必须明确设计：**空态 / 加载态 / 进行中态 / 失败态 / 无权限态 / 长列表态**。

## 3. 逐页验收准则（黄金图未覆盖页 = 本节即黄金图）

### 3.1 首页 `/teacher-v3/prep`
**结构以用户提供的基线截图（2026-09-14 `屏幕截图 2026-09-14 090510.png`）为骨架**——用户明确表示该结构是「原来的效果」，当前实现把它降级成了平铺列表。必须恢复并把它做到黄金图质量：

自下而上的结构（顺序固定）：
1. 顶栏：品牌「智学备课」+ 场景副标题「多轮对话 · 教材学情 · 教案课件一体生成」+ 状态胶囊 + 右侧「任务」「教师身份（真实姓名 + 高中数学）」。
2. 问候 + 提问（居中）：「{上午好/下午好/晚上好}，{教师姓名}同学」+ 主问句「今天想备什么课？」（24-28px/700，**高度受控：整块 ≤ 220px**，不得挤掉下方功能内容）。
3. 一行式 NL 主输入卡：左侧回形针图标 + 占位「请继续上一次备课会话 / 告诉 AI 你今天想准备什么课」+ 右侧蓝色圆形发送钮（40px，主蓝 #2563EB）。**发送钮必须与输入框垂直居中且右内边距一致（禁止错位）**。
4. 输入卡下方一行轻提示（13px 灰）：`支持语音输入 · 添加已授权资料 · 选择教材章节`——每项是可点击的真实动作或诚实禁用，不是纯装饰文字。
5. 四个入口卡（等宽网格，白卡 + 发丝线 + 图标 + 标题 15/600 + 说明 13 灰）：**从教材开始 / 添加资料 / 选择模板 / 继续备课**。每卡必须真实跳转或诚实禁用（禁用要有原因文案）。
6. 「最近备课」区：标题 + 右侧「查看全部 ›」；列表**按 今天 / 本周 / 更早 分组**，每条 = 课题名 15/600 + 教材·章节·课时 13 灰 + 状态徽标 + 相对时间；支持按课题名检索；空态有引导。
7. 悬浮「AI 助教」入口（右下，主蓝圆形，与截图一致）。

**禁止**：
- 平铺 40 条无分组、无检索；
- 输入框与发送钮错位；
- 页面内出现后端错误原文（如「当前账号还没有已确认的教学班级，请在统一身份平台创建或加入后重试」）——改为行内软提示 + 可继续操作；
- 「处理中…」这类无锚点的浮动占位压住内容；
- 硬编码课程/教材/教师数据。
- 教师姓名/学科必须来自真实用户档案；无真实字段时**诚实省略**，不得显示「老 老师」这类假值。


### 3.2 对话面（备课方向确认）
- **必须有**：可滚动的消息流（教师右 / AI 左）、AI 头像与名称、消息时间、发送中态（乐观占位 + 失败重试）、流式或分阶段进度、选择卡（结构化选项）与已选回显、底部输入条（多行 + 麦克风 + 发送）。
- 选择卡样式：白卡 + 发丝线 + 选项为浅蓝胶囊（hover 描边变主蓝），已选项主蓝实心；**选项来自后端真实数据**。
- **禁止**：无消息流只有输入条；发送无反馈；错误以 toast 一闪而过且状态不明；AI 用"请提供…"反复追问而非先给方案。

### 3.3 选择卡 / 抽屉 / 弹层
- 与工作台同一 token；抽屉从右侧滑出（宽 380px），带遮罩与关闭；弹层圆角 14px + 轻阴影。

### 3.4 顶栏（三 Tab 共用，已有黄金图约束，此处补充）
- Tab 居中、激活蓝字 + 2px 蓝下划线 + 浅蓝底；右侧工具按页不同；**无套娃**。
- 课程标题区：`{课时标题} · {第N课时}` + 元信息（教材版本 · 班级 · 时长）；缺字段则**省略该项并保持排版稳定**，禁止出现「第一课时 · 第1课时」这类重复/空值拼接。

## 4. 内核验收准则（后端）

### 4.1 蓝图提议（源头）
- 每个桶（objectives/key_points/difficult_points/concepts/theorems/inquiry/homework/reflection）**非空且互不重复**；文本去重率 ≥ 90%，禁止同一句出现在两个桶。
- `examples` 必须非空：教材例题来自 `textbook_problems`（标注来源），无则给 AI 生成的变式并标注 `ai_generated`。
- `lesson_flow` **时长合计 ≤ 课时时长**（45min 课时 → 合计 ≤45，建议 40-45）；节点标题不得含编辑标记。
- 教材依据（source_ref）覆盖率：objectives/key_points/concepts/theorems 至少各 1 条带真实 locator。

### 4.2 PPT 投影（页面计划）
- 禁止"桶转储"。页序必须**跟随 `lesson_flow` 教学节点**（每节点 1-2 页），另加 标题页 / 学习目标页 / 小结页 / 作业页。
- **角色语义正确**：`definition` 只用于定义；目标/要点用 `bullets`/`steps`；推导步骤用 `steps`；对比用 `table`。
- **页间去重**：任意两页的 `elements` 文本集合交集 ≤ 1 条；禁止"重点梳理/课堂小结"页复读全桶。
- 数学页必须有 `figure`（`math_object`），且 `a/b/c` 参数自洽。
- 每页 ≥2 条真实内容项；相邻页 `layout_hint` 不重复；页数 8 ≤ N ≤ 12。
- 可见文本零占位符、零编辑标记。

### 4.3 教案投影
- 六章齐全非空：教学目标 / 教学重难点 / 教学过程 / 板书设计 / 作业布置 / 教学反思。
- 教学过程表行 = 蓝图 `lesson_flow` 节点，**一一对应**；时间列合计 ≤45min。
- 板书三栏（文字要点 / 数学图形 / 公式区）均有内容。
- 元信息四项（学科/教材/班级/课时）真实；标题清理占位后缀。
- `warnings` 中的 `no_*_evidence` 必须在提案阶段消除（不是投影阶段掩盖）。

### 4.4 速度
- 消息受理 ≤ 1s（202）；**首条 AI 回复内容可见 ≤ 20s**；蓝图产出 ≤ 90s；PPT+教案投影 ≤ 30s（投影无 LLM）。
- 全链路（新建会话 → 看到 PPT 与教案）≤ **4 分钟**，且进度可见（真实阶段事件）。

### 4.5 导出（反幻觉终审）
- 真实落盘：PPTX（≥8 页、`<a:t>` 可编辑文本存在、无修复弹窗 XML 合法）+ DOCX（六章齐全）。
- 导出物必须包含教师编辑后的最新修订；重进后仍一致。

## 5. 工作流纪律（团队模式）

1. **编码者 ≠ 裁决者**：工程师实现并自截图；主控独立重跑脚本、独立发起真实请求复核，逐图对照黄金图/本文件裁决。
2. **每一轮交付必须包含**：代码 + 自检清单 + **真实登录态 1672×941 DPR1 截图**（每个功能一张，禁止拼图代替）+ 真实接口/DB 证据摘录。
3. **文件归属制（防覆盖冲突）**：每轮一个文件只能有一个 owner，跨 owner 的共享文件必须由 owner 串行修改。
4. **禁止"编码通过即验收"**：没有真实界面截图的功能一律视为未完成。
5. **不得破坏他人 dirty**：见根 `AGENTS.md` 第 3 条。
