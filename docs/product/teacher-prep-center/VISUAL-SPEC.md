## 5. 交互与状态红线（反空壳）

1. 任何按钮 = Trigger + State Change + Result 三者齐备；仅 Toast 无业务结果 = FAIL。
2. 计数/进度/页码/「已保存」等一切数字与状态来自后端真实数据；禁止 setTimeout 假进度。
3. AI 对话必须携带「正在修改」目标上下文；AI 宣称的修改必须真实落到会话状态并持久化。
4. 未实现的能力不得渲染入口（隐藏或明确 Coming Soon）。
5. 教师手工编辑必须持久化，且下次 AI 生成不得静默覆盖。
6. 刷新/重进会话：教学设计、PPT、教案、对话全部还原。
7. 数学红线：公式/图形/参数关系必须数学正确（a²=b²+c² 联动）；视觉再美、数学错 = FAIL。
