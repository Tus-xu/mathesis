### 1.2 字体与层级

| 角色 | 字号/字重 |
|---|---|
| 首页主问句 | 32–34 / 700 |
| 页标题（文档标题） | 22–24 / 700 |
| 区标题 | 15 / 600 |
| 节标题（教案 1/2/3 章） | 17 / 700 |
| 正文 | 14 / 400，行高 1.6（教案 1.7） |
| 辅助说明 | 13 / 400 |
| 元信息 | 12 / 400 |
| 缩略图描述 | 11 / 400 |

**字体栈**：系统中文栈；**数学一律 KaTeX**，禁止裸 LaTeX 上屏（含章节标题里的 `$n$`）。

### 1.3 圆角 / 阴影 / 间距

- 圆角：大面板 14｜卡片 12｜按钮与输入 8｜胶囊 999｜缩略图 8。
- 阴影：**静态面一律不投影**，只用 1px 描边；仅浮层（抽屉/弹层/悬浮条）用 `0 8px 24px rgba(15,23,42,.08)`。
- 间距：工作台内容区左右内边距 24px；卡片内边距 16–20px；同级元素间距 12–16px；区块间距 20–24px。
- **反失重铁律**：禁止「大面积空白 + 小内容块悬浮」。任何一屏，内容必须撑满或按比例填满可用高度。

### 1.4 图标

线性 1.3–1.5px stroke、16–18px，颜色继承文字；**禁止 emoji 充当功能图标**（黄金图除问候语 👋 外无 emoji）。

  4. `最近备课 N` 区标题 + 右 `查看全部 ›`。列表行高 68、行间 8：

### S2 备课对话（`golden1.png`）

- 无教学流程时，对话是主内容；有教学流程时，对话进顶栏「对话 n」入口 + 右侧 420 抽屉（已实现，保持）。
- 结构：面包屑 `← 返回备课中心` → 会话头卡（图标 + 标题 + 元信息 + **4 步进度** `对话交流 → 教学设计 → 生成PPT → 生成教案` + 右「进行中」徽标）→ 消息流 → 底部 composer。

- **结构化结果卡**（备课信息确认 2×2 网格 / 教学意图 / 下一步建议 / 确认按钮组）占满宽度，禁止塞进气泡。

- 右栏：`教材依据` / `相关资料` 两 Tab；教材依据 = 书封 + 教材树（当前节高亮）+ `查看教材 >`；相关资料 = 资源行（图标 + 名 + 大小 + 下载/播放）。

### S4 PPT（`PPT.png`）

1. 三栏：缩略栏 200（白底右发丝线）/ 画布区 `#EEF2F8` / 智能面板 280（白底左发丝线）。
2. 缩略条：序号 + 160×90 缩略图（**必须真实渲染页面内容，禁止空白**；选中 2px 主蓝描边 + 浅蓝底）+ 环节名 13/700 + 一句描述 11 灰。
3. 画布工具条：`＋ 添加页｜T 文本｜Σ 公式｜◇ 数学图形｜🖼 图片｜≣ 备注`（图标必须线性，非 emoji）。
4. 画布：16:9 白底圆角 8 柔影，宽 ≥ 980 **居中**；页眉（左蓝短竖条 + 课题 13 + 右版本 11 灰）；标题行（40 蓝方序号徽标 + 28/700）；定义带（浅蓝圆角面板）；数学图形（坐标系 + 参数化曲线 + 焦点/辅助线/标注，**实时由参数生成**）；公式胶囊；知识卡；页脚右下 `用数学的眼光观察世界` 斜体 12。

| 失败 | 中文软提示 + 人话原因 + 重试按钮；**禁止后端原文/堆栈上屏** |
| 未保存/保存中 | 顶栏真实「已保存 HH:MM」；无则整项隐藏 |
| 离线/401 | 提示登录失效 + 跳登录，**不清空既有编辑内容** |

## 5. 反空壳与数学红线

1. 一切数字（页数 / 资料数 / 已保存时间 / 进度 / 版本号）来自后端真实数据。
2. 未实现的能力**不渲染入口**（不是变灰）。
3. 公式与图形必须数学正确（`c² = a² − b²`、焦点 `F₁(−c,0)/F₂(c,0)`、改 a/b 必须联动图形与公式）。
4. 刷新/重进：教学设计、PPT、教案、对话全部还原。
5. **工程黑话零泄漏**：`（教师修订）`、`（教师A10编辑验证-*）`、`W1A-E2E-*`、`未命名备课`、裸 `$n$` 一律不得上屏。
6. **单一 composer 铁律**：任一屏任一时刻只允许存在 1 个 AI 输入条。

## 6. 验收协议

1. **截图口径**：1672×941、DPR=1、真实登录态、真实后端；逐功能一张，禁止拼图、禁止设计图代替。
2. **性能证据**：涉及性能的页面必须附首屏稳定耗时（Playwright 截图耗时）与关键长任务墙钟。
3. **交叉审核**：实现者与审核者不得为同一人；审核者逐区对照黄金图/本 spec，不达标直接 `REWORK`。
4. **产物证据**：PPTX / DOCX / PDF 必须实际打开检查（文本可编辑、公式正确、无溢出、无重复页）。
5. **数学证据**：公式/图形参数一致性核对。
6. 交付归档：`deliverables/teacher-prep-center/<round>/`（截图 + 自检清单 + 回放命令）。
7. 同一问题连续两轮无接近 → **回滚 + 换路径**，禁止继续叠加 patch。
