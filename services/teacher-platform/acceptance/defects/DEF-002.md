# DEF-002 · 8100 端口被 student-api 占用（教师平台起服将冲突）

| 项 | 内容 |
|---|---|
| 编号 | DEF-002 |
| 严重级 | **P2**（开发环境阻塞项：teacher-api 按架构必须占用 8100，当前起服即端口冲突） |
| 所有者 | **B3 + 用户**（部署/端口协调；学生端 8100 服务属用户当前会话遗留） |
| 状态 | OPEN（2026-09-07 登记） |
| 复现 | `curl http://127.0.0.1:8100/openapi.json` → `info.title = "student-api (B4 features)"`；`netstat -ano | findstr :8100` → PID 27280 LISTENING |

## 现象

02-ARCHITECTURE §1.3 端口定案：学生端 api :8000、teacher-api :8100。实测本机 8100
当前由 **student-api** 监听（21 条 /api/v1/* 路由，/healthz 返回 `{"service":"student-api"}`）。

## 影响

- teacher-api compose 起服即端口冲突（M1 Gate「/healthz 全绿 ≤3 分钟」直接被阻）；
- B5 已在 `tests/contract/export_api_inventory.py` 加身份校验：OpenAPI title 不含
  "teacher" 一律判 `unavailable`，防学生端契约污染教师端对账基线。

## 出口条件

1. student-api 迁回 :8000 或教师端临时改用备用端口（后者必须同步改 02-ARCHITECTURE §1.3 + vite proxy，走 IFC）；
2. teacher-api :8100 /healthz 可用后，本单由 B5 复验关闭。
